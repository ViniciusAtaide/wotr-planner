# The prerequisite rewrites that narrow who qualifies and are written all the same (ticket 308a's fix round), read by
# `game-check --write prerequisites`.
#
# The writer turns each GUID the game's prerequisite names into whichever planner entry maps it. Where the planner
# grants the game's blueprint under another entry, or a grantor's rows are still the planner's, a rewrite would refuse
# characters the game allows, and the game check can't see it, since it compares GUIDs. So the writer compares each
# entry's compiled tree before and after, and leaves the entry whole (listed `narrows: … -> <ticket>`, the ticket that
# owns the fact's blueprint by the writer's `owner`, or 308 when it names none) when the rewrite
#   - drops a fact the old tree accepts outside a `Not` and the new one doesn't name, or
#   - adds a `Not` of a fact the old tree doesn't refuse (the entry's own blueprint aside: refusing itself, or another
#     entry of its own GUID, is the game's NoFeature exactly),
# unless this file names that entry and that narrowing.
#
#   <entry> -> <reason>              the entry's reason, for each of its narrowings below
#   <entry> / drops <fact>           one narrowing, under its entry's reason
#   <entry> / adds Not <fact>
#   <entry> / drops <fact> -> <reason>    or with a reason of its own
#
# The entry and the fact as the report names them (`feat extra-channel`, `feature cleric/channel-energy`). The reason
# says why the narrowing moves toward the game: the game blueprint and GUID the entry's prerequisite names, and, for a
# dropped fact, that no planner holder of it is granted that blueprint (`game-check refs` / `granted-by`, and the
# check's `progression rows / … game only` findings, none of which names the blueprint); for an added `Not`, that the
# planner entry it refuses is the only one mapping the game's blueprint. A narrowing this file doesn't name stays
# blocked, its `known.txt` line naming the ticket that owns it.
#
# A narrowing line no rewrite makes (its entry written, or the data changed) would allow that narrowing again unseen:
# the game check lists it and fails (ticket 308g), as it does a stale `known.txt` line. A data slice removes the lines
# of the entries it writes. A reason line with no narrowing of its entry is refused.
