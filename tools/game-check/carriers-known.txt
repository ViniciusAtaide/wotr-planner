# does a line no hit matches (stale). Both are printed.
#
#   <entry> | holds: <fact> granted by <grantor> <GUID>, which <planner entry> doesn't grant -> <ticket>
#   <entry> | left whole: <fact> granted by <grantor> <GUID>, which <planner entry> doesn't grant -> <ticket>
#
# `holds`: the tree the data holds refuses a holder of the grantor's planner entry that the game allows, since that

# session's to set: 307 (the carriers) as the audit prints it, or the ticket of a slice that will remove the hit.

# main checkout's root:
#
#   cargo run -q -p game-check -- --carrier-audit --known-format > tools/game-check/carriers-known.txt.new
#   mv tools/game-check/carriers-known.txt.new tools/game-check/carriers-known.txt
#
