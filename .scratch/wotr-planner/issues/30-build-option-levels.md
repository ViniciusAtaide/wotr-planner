An option can grant over class levels: a bloodline, school, order, spirit, way or combat style has rows by **option level**, the levels of the classes its selection names added up, and gives each row as that level reaches it (all of them at once when taken late). Archetypes skip option levels, limit the options (one is granted with no pick) or take only a second option's feat list; a bonus slot picks from the held option's list; a selection can be held twice; an option row can grant a selection; a feature can grant one row of the held option; a Primalist's choice replaces a row. Dragon Disciple checks spontaneous arcane casting and "a Draconic bloodline or none", continues a sorcerer's bloodline and gives anyone else one. ### Rust (`rules`)

- **Option rows.** `SelectionOption.levels: Vec<OptionLevelRow { level, features, feats, selections, feat_list }>`; `feat_list` is the option's list from that level on (a ranger style names one per stage). Option features belong to the class that owns the selection.
- **The grant is the selection.** `FeatureSelection.option_levels` (the classes whose levels make the option level: sorcerer and Dragon Disciple), `skipped_levels` (Seeker), `feat_lists_only` (Crossblooded's second bloodline), `only_without_option` (Dragon Disciple's Blood of Dragons), `pool_of` with `SelectionOption.pool` (a selection offering the held option's pool: ticket 31's revelations, test world only). An archetype that changes the grant has its own selection sharing the options it allows (ticket 25's shared options, so the held option keeps one key); a selection offering one option is granted with no pick. `FeatureSelection::offered`.
- **Slots.** `FeatSlot::OptionList { selection }`: the lists in force of the options held that the selection offers (Crossblooded: both); it's checked after the level's selections, so a style picked at 2 feeds the slot at 2. `SlotId::OptionSelection { level, index }` (a selection an option row grants, at the level that reaches it) and `SlotId::MythicSelection { rank, index }` (a mythic ability's). `MythicAbility.features`/`selections` (Bloodline Ascendance, Second Bloodline/Spirit; the general pick is filled first, so its slots follow it).
- **Other shapes.** `SelectionOption.replaces_row_of` (a Primalist's rage powers skip that level's bloodline row, taking back what it gave); `Feature.option_row: Option<OptionRow { selection, level }>` (Bloodline Ascendance: the bloodline's 20th-level row); `Feature.daily_choice` and `Engine::daily_choices(state)` for the sheet's note; `Class.spontaneous`, `Archetype.spontaneous: Option<bool>`; `Prerequisite::SpontaneousSpellLevel { spell_type, level }` and `Prerequisite::NoOptionFrom(selection)` (no option keyed under it held).
- **State.** `option_levels`, `option_feat_lists`, `spontaneous_{arcane,divine}_spell_level`; `option_level`, `spontaneous_spell_level`, `holds_option_of`.
