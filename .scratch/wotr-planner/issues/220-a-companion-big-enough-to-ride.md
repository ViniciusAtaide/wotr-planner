# A companion big enough to ride

Type: design
Status: open
Blocked by: [217](217-animal-companions-stage-1.md)
Model: no agent. A design ticket: the user decides, in a grilling session with the main session.
Map: [WotR Build Planner](../map.md)

## Question

Ticket [174](174-animal-companions.md)'s Answer, item 11 (user, 2026-11-14): a rider bonus counts whenever the Build has the animal, "since this feature will be very complex depending on the size buff we'll deal with it in a subsequent ticket". In the game a mount has to be larger than its rider: a Medium triceratops grows Large only at companion level 7, a Small character can ride a Medium animal, and size buffs (Enlarge Person, a druid's or an Aeon's) change both sides.

To decide: whether the planner checks the size at all; if so, from what (the race's size, the animal's size and its evolved form by companion level, and which size changes: spells, class features, items); what a rider bonus does when the animal is too small (not counted, or counted with a note); and how this meets [143](143-switched-on-abilities.md)'s riding switch.
