### Rust (`rules`)

- **Pick order.** `level_slots` gives a level's class selections, then its class feat slots (option-list slots last, as before), the race's slots, the general slot; options' row slots still come after. `LevelSheet.slots` is in that order.
- **Mythic feats with a value.** `MythicFeat.parameter` and `repeat` (as on `Feat`) and `removes_racial_penalty`; `Pick::MythicFeat { feat, parameter }` (`Pick::mythic_feat`, `mythic_feat_for`). The check takes a value of its kind (`ParameterMissing`, `WrongParameter`), once per value; the picker lists one per value; `CharacterState.mythic_feat_values`.
- **Prerequisites.** `Prerequisite::FeatIfValue { value, feat }`: `feat` is needed only when the pick is taken for `value` (Armor Focus). `Prerequisite::Not(Box<..>)`: holds when its child doesn't (the slayer's windows).
- **Fixed values.** `ClassLevelRow.feats_for`, `ArchetypeLevelRow.feats_for` (and `EffectiveRow`): `BTreeSet<FeatValue { feat, value }>`, held for that value only.
- **Options with a value.** `SelectionOption.parameter` (what the pick names when there's no chosen feat; its rows' `chosen_feats` use it) and `values` (the values it may name; the check refuses another with `WrongParameter`, the picker offers only those). A selection whose one option takes a value is a pick, not a grant.
- **A race's lists.** `Race.feat_lists`, in `GameData::feat_lists`; a race's slots may name only its own.
- **Floors.** `Feature.bab_floor` and `skill_ranks_at_least_mythic_rank`; the state's `bab_floor` and `skill_ranks_at_least_mythic_rank` follow the features held, and prerequisites read `prerequisite_bab()` and `prerequisite_skill_ranks()` (the sheet's BAB and ranks don't change).
- **Destiny Beyond Birth.** The walker keeps the race's penalties from Build start and adds them back to the character's own scores while a mythic feat with `removes_racial_penalty` is held (the base scores keep them).
- **Data check.** `IfValueOfWrongKind`, `ParameterBesideChosenFeat`, `OptionValueOfWrongKind`; a feat granted for a value takes one of its kind (`ValueOfWrongKind`); mythic feats' repeats and "same value" are checked like feats'; `MisplacedBonusList` covers a race's slots (reworded); `Not` is recursed into.
