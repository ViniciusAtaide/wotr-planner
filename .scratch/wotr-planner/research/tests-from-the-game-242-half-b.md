## Rules the code contradicts (all WrathDecompiled 6ce4a6b)

- R-order: inside one level-up, selections of the same priority (all feats, talents and class options are `Features`) apply in the order the player picks them, each checked against the preview with the earlier ones applied (UnitLogic/Class/LevelUp/Actions/SelectFeature.CalculatePriority and .Check, LevelUpController.AddAction). The planner's fixed slot order within a level (MetLater refusals, pick_order.rs:24) refuses what the game allows. Bands do keep an order: Race, Class, Archetype, Heritage, … Deity, Path (domains, bloodlines, mysteries…), Features, Spells; MythicAbility before Features.
- R-selection-fact: a selection is held as a fact once its level is reached, so "needs a talent held" is "has the slot" (LevelUpHelper.AddFeaturesFromProgression; part 2).
- R-parameter: a parametrised feature repeats per value, not per feature (BlueprintParametrizedFeature.CanSelect).
- R-proficiency: WeaponFocus, WeaponSpecialization and ImprovedCritical have RequireProficiency, checked on the feature's own IgnorePrerequisites flag, so even a prerequisite-free slot (the warpriest's WarpriestWeaponFocusSelection) offers only proficient weapons (BlueprintParametrizedFeature.CanSelect).
- R-ignore: selections flagged IgnorePrerequisites skip MeetsPrerequisites (part 3 R2: Life-Bonding Friendship, Pentamic Faith, ranger styles).
- R-levels: per-blueprint level gates, not 2 × level (infusions, wild talents); archetype-listed progressions count levels with offsets (BlueprintProgression.CalcLevel; part 3 R4: the Divine Hunter's −2).
- R-rank: a step on class level (ContextRankConfig, AddFeatureOnClassLevel) follows the class level whether or not a later row is traded away (part 1, the Primalist).
- R-repeat: a selection skips the rank check (BlueprintFeatureSelection.CanSelect); the ten Extra-talent selections cap themselves at 3 with a PrerequisiteCondition (ContextConditionBuffRank), Extra Rage Power and Favorite Metamagic have no cap (medium confidence on Favorite Metamagic).
