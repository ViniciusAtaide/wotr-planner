# Notes on the game data, one file per ticket

A ticket that changes the game data writes its note here, as `<ticket>-<slug>.md`, instead of adding to `../README.md`. Each ticket having its own file lets data tickets be built side by side: the shared README was the one file every data ticket edited.

`../README.md` keeps the format of the files, the two behaviour tests, and the notes written before this folder existed (tickets up to 193). It is not edited for a new ticket unless the format itself changes.

## What a note holds

- What the data says now, with the keys.
- The guide sentence or table it rests on: the page, the heading, a paraphrase.
- Each decision and who made it; each inference, marked as one.
- What it does not model, and why.
- The real-data test that pins it.

Keep it to what a later ticket must know before editing the same rows.
